⌨ curl-compatible API

Fetch any sheet directly with curl:

curl localhost:8505/{namespace}/{name}   # plain text
curl localhost:8505/{name}              # default namespace

# REST API
curl localhost:8505/api/sheets          # list all
curl localhost:8505/api/search?q=git    # search
curl localhost:8505/api/namespaces      # list namespaces
curl localhost:8505/api/tags            # list tags

# Create
curl -X POST localhost:8505/api/sheets \
  -H 'Content-Type: application/json' \
  -d '{"name":"my-sheet","namespace":"tools","content":"# My Sheet\n..."}'

Tip: Browsers get HTML preview, curl gets raw markdown.
